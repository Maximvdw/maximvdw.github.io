# maximvdw.be

Personal website and CV of Maxim Van de Wynckel, built with [Eleventy](https://www.11ty.dev/).

## Development

Prerequisites: Node.js 22, Yarn, and Docker (HTML validator).

```bash
# Start the HTML validator on http://localhost:8888
docker compose up -d validator

# Install dependencies
yarn install

# Dev server with live reload
yarn start

# Production build (output in _site/)
yarn build
```

## Scripts

| Command | Description |
| --- | --- |
| `yarn start` | Start the Eleventy dev server |
| `yarn build` | Build the site, then generate WebP image variants |
| `yarn clean` | Remove `_site/` |
| `yarn optimize-images` | Regenerate WebP variants of profile, social and logo images |
| `yarn generate-favicons` | Regenerate the favicon set |

## Structure

- `_data/` — structured data (personal, employment, education, skills, teaching, ...)
- `publications/`, `posts/`, `presentations/`, `portfolio/` — content
- `cv/` — CV templates (Europass XML; the Europass PDF is generated by the CI workflow)
- `_layouts/`, `_includes/`, `_scss/` — templates, partials and styles
